Швидкісний режим</div><div class="rule">У місті встановлені автоматизовані радари, які фіксують порушення швидкісного режиму та автоматично надсилають штрафи водіям, які перевищують дозволену швидкість. ДТП</div><div class="rule">У разі дорожньо-транспортної пригоди (ДТП), всі учасники зобов&#x27;язані негайно зупинитися, забезпечити безпеку на місці події, викликати поліцію для фіксації факту аварії та подальшого розгляду. Поворот з неправильної смуги</div><div class="rule">Забороняється виконувати поворот з смуги, не призначеної для цього маневру.
